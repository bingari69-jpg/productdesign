# 메쉬 리클라이너 게이밍의자 디자인 개선

2026-10-29 · 제품 외형 콘셉트 검토

## 요청과 수정

사용자 회사 디자이너의 시제품 사진과 제닉스 마루체어 상품 링크를 참고해 올드한 인상을 개선한다. 메쉬 소재·PC방 사용·리클라이너 제품 성격을 유지한다. 초기 A/B안은 사용자에게 두 안 모두 디자인이 좋지 않다는 평가를 받았다. 사용자는 여러 디자인을 실제 검색하고 우수한 디자인을 적극 참고하도록 요청했다.

반려된 초기안은 봉제선·퀼팅과 윤곽 정리에 머물렀다. 수정 방향은 기존 외형 유지의 가정을 풀고 등판·헤드레스트·프레임을 구분해 새로 설계하는 것이다. 프레임 변경·금형비·인체 적합성은 미확정이다. 두 안의 반려를 모든 사용자의 보편적 취향으로 기록하지 않는다.

## 관찰

- 사용자 사진: 큰 좌우 어깨 날개, 겹쳐 보이는 머리·중간·하단 쿠션, 다이아몬드 퀼팅과 파이핑, 두툼한 메쉬 표면, 독립 높이조절형으로 보이는 팔걸이.
- 올드하다는 인상을 주는 주요 원인은 큰 날개와 분절된 쿠션·장식의 조합이라는 디자인 해석이다. 제품 기능 결함을 확인한 것은 아니다.
- 사진은 정면 위주로 내부 프레임·폼·정확한 치수·리클라이닝 축·작동 각도·하중을 확인할 수 없다. 보존/호환 여부를 확정하지 않는다.
- 제닉스 공식 상품명은 제닉스아레나 마루체어 메쉬 중역 사무용 PC방 컴퓨터 게이밍의자로 확인했다. 공식 대표 이미지를 내려받아 실제 열었고, 원본과 비슷한 쿠션 분할과 퀼팅 구성을 확인했다. 상세 사양 전체·원단 시험 결과는 미확인이다.

## 수정 시안의 세 방향

1. **01 AIRFRAME**: 장력 메쉬 등판+별도 프레임+분리 헤드레스트, 쿠션 좌판. 기존 폼을 천갈이하는 범위보다 등판 구조 개발이 커진다.
2. **02 ARCH**: 조형적인 외곽 셸, 일체형 머리 지지, 단일 통풍 슬릿, 메쉬를 씌운 폼 접촉면. 기존 리클라이너의 쿠션 성격을 발전시키는 방향이나 프레임 재사용은 아직 모른다.
3. **03 KNIT LOUNGE**: 하나로 이어지는 입체 니트 등판과 작은 머리 지지, 유기적인 허리 윤곽과 넓은 쿠션 좌판. 니트 개발·폼 또는 지지체·내구성 검증이 필요하다.

비교 시안의 오발·바퀴와 보이지 않던 하부는 시각화상의 가정이다. 원제품과의 호환이나 기구 완성도를 주장하지 않는다. 생성 이미지는 치수 도면·양산 설계가 아니다.

## 다음 단계에서 필요한 제작 자료

방향 선정 후 해당 의자의 정면·측면·후면·리클라이닝 상태와 프레임/폼 도면을 비교해 변화 범위를 정한다. 좌판 높이·유효 폭/깊이·등판 높이·축 위치·머리받침 위치·팔걸이 간격은 실측 또는 기존 도면으로 정한다. PC방 관리 관점에서는 원단 오염·마찰·세척, 봉제 부위, 교체 가능한 접촉 부품을 시제품에서 확인한다.

새 장력 메쉬 등판은 원단 고정·장력·프레임 강성을 별도 검토한다. 니트 패턴의 외형이 실제 지지·통기를 보증하지 않는다. 외형 확정 후 착좌·리클라이닝 간섭·전도·내구 시험의 조건과 판정 기준을 제작사와 정한다.

## 생성과 검증 기록

Codex 내장 이미지 생성 도구 사용. 수정 프롬프트 전체는 이미지생성_프롬프트_v2.txt에 저장. 사용자 시제품과 실제 연 레퍼런스 4개를 입력한다. CAD 실행·실물 제작·착좌 시험·구조 강도·원가·제조사 확인은 미수행이다.

수정 시안 저장: 개선시안_v2_3방향.png. 실제 생성 결과를 열어 01의 투명 장력 메쉬·분리 머리받침, 02의 단일 통풍 슬릿·외곽 셸·독립적으로 보이는 허리 패드, 03의 니트 표면과 연속 등판을 확인했다. 세 방향의 재질 표현·외곽·머리 지지가 구분되며 초기안의 다이아몬드 퀼팅은 보이지 않는다. 02는 목표보다 허리 패드가 두툼하게 분리되어 보인다. 03은 실제 생산할 니트 조직과 지지구조를 별도로 개발해야 한다. 생성된 기구·팔걸이·베이스의 작동은 이미지로 검증하지 않았다. 현재 추천은 포근한 PC방 리클라이너의 성격과 외형 정돈을 연결하는 03이며, 게이밍 장비 느낌을 강조하려면 02를 대안으로 제시한다. 사용자 선택·만족 여부는 미확정이다.
