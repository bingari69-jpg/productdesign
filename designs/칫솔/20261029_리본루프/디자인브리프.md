# RIBBON LOOP · 수동 칫솔 외형 콘셉트

2026-10-29. 사용자 요청: 제품 디자이너 스킬을 사용해 전혀 새롭고 새로운 인상이 분명한 칫솔 디자인. 수동 칫솔로 가정해 진행한다. 의자 작업의 기존 철재 프레임·사출 금형 금지 조건은 이 작업에 적용하지 않는다.

## 설계 의도

막대형 손잡이를 두 갈래의 흐르는 리본으로 나누고 다시 연결해 하나의 긴 빈 공간을 만든다. 한쪽 면은 완만하게 비틀어 넓은 엄지 받침으로, 다른 면은 손가락이 닿는 곡면으로 설계한다. 주요 차별점은 색이나 무늬보다 열린 공간과 입체적인 손잡이 구조다.

내부 탐색에서는 별도 받침 없는 자립형, 교체 헤드형, 열린 루프형을 비교했다. 자립형은 하단이 비대해질 수 있고, 교체형은 결합부·교체품 개발이 추가된다. 현재 요청의 새 외형과 단순한 구성에 맞춰 루프형 하나를 시각화한다. 다른 안의 시제품을 만들거나 성능 비교 시험을 수행한 것은 아니다.

## 핵심 구성

- 하나의 작은 타원형 브러시 헤드와 가는 목.
- 위아래가 연결된 비대칭 리본 루프 손잡이. 가운데는 관통된 긴 창.
- 넓고 완만한 엄지 받침과 반대쪽 손가락 접촉면에만 작은 미끄럼 방지 패치.
- 웜아이보리 몸체, 연한 미네랄 아쿠아 접촉 패치, 흰색 모 중심의 색 조합.
- 전자 기능·교체 헤드·움직이는 관절·센서·별도 거치대는 포함하지 않는다.

## 기능과 근거의 구분

기존의 작은 칫솔 헤드·부드러운 모라는 기본 조건을 유지하며 손잡이 구조를 탐색한다. ADA는 부드러운 모와 사용 후 세척·공기 건조 등을 권고한다. 이 지침은 이 콘셉트의 임상 성능을 증명하는 자료가 아니다.

- 관통 창과 넓은 곡면은 손가락 위치를 바꾸고 물로 씻어내기 쉽게 하려는 설계 의도다. 실제 세척성과 손 크기별 그립감은 미검증이다.
- 비틀린 손잡이를 압력 센서나 과압 방지 장치라고 표현하지 않는다. 강성과 휨은 시험 전 모른다.
- 항균·살균·플라크 제거 향상·친환경·재활용 가능성·인증을 주장하지 않는다.
- 세계 최초나 특허 가능한 발명으로 확인한 것이 아니다. 이번 요청을 위해 만든 새로운 외형 제안이다.

## 제작 초안

몸체 재료 후보는 PP, 접촉부 후보는 몸체와 적합성을 확인할 TPE, 식모는 칫솔용 부드러운 필라멘트다. 구체 등급·접합 방식·내약품성·피부/구강 접촉 적합성은 공급사 자료로 확정한다. 몸체 단일재질과 별도 패치 없는 안도 원가·재료 분리를 위해 비교할 수 있다.

리본의 비틀림과 구멍에는 사출 이형·분할선·언더컷 검토가 필요하다. 단순 2판 금형으로 확정하지 않는다. CAD에서는 손잡이 창이 금형 개폐 방향으로 열리는지 확인하고 필요하면 비틀림을 줄이거나 단면을 조정한다. 식모 장비가 작은 헤드에 접근할 수 있는지와 앵커 유지·헤드 강도를 검토한다.

## 디자인 치수 가정

이미지 생성을 위한 외형 목표일 뿐 도면·실측값이 아니다: 전체 길이 약190mm, 헤드 길이 약25mm, 손잡이 최대 폭 약22mm, 손잡이 외형 두께 약10~14mm. 실제 레일 단면·목 두께·모 높이·모 끝가공은 CAD·식모업체·시제품으로 정한다.

## 검증 순서

1. CAD로 하나의 연속 몸체와 리본 단면·필렛·금형 분할을 정리한다.
2. 손잡이 외형 모형으로 마른 손·젖은 손, 여러 손 크기에서 엄지 위치·회전 제어·헹굼을 확인한다.
3. 목과 루프의 굽힘·비틀림·낙하, 패치 접합, 필라멘트 유지와 끝가공 등 제품에 맞는 시험 조건을 정한다.
4. 실제 사용 제품은 적합 재료와 생산 공정으로 제작한 시제품으로 검토한다. 외형 확인용 출력물을 기능 시험 완료 제품으로 취급하지 않는다.
