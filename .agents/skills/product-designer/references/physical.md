# 실물 제품: 외형에서 제작 구조로

## 요구와 사용 장면

사용자·환경·주 기능에 따라 크기·하중·접촉 부위·설치 공간·이동/세척/수리·수량·가격 목표를 정한다. 미정이면 가정과 변경 매개변수로 둔다. 인체 치수는 해당 사용자 집단의 근거를 찾고 평균값 하나로 모두를 대표하지 않는다.

놓기·잡기·열기·작동·닫기·보관 경로를 확인한다. 장식이 그립·시야·방열·조립·청소를 막지 않게 한다. 실물+앱은 물리 조작과 앱 조작의 우선순위·피드백을 연결한다.

## 치수와 구조

새 설계는 다음 결정이 이어지도록 한다. 작은 외형 수정은 기존 결과를 직접 편집하고 새 기능·구조가 달라질 때 필요한 검토로 되돌아간다.

| 설계 결정 | 확인할 것 | 적합한 표현 |
|---|---|---|
| 형태 탐색 | 비례·설치 자세·그립 방식이 다른 대안인가 | 보통 2~3개 작은 스케치·실루엣 |
| 형태 정리 | 정면과 측면이 같은 제품을 설명하는가 | 선화·단색 모델·기준 비율 |
| 내부 공간 | 내용물·부품·손·이동 경로가 들어가는가 | 필요한 단면·공간 배치 |
| 기구·결합 | 무엇이 움직이고 어디에 붙으며 고정되는가 | 동작 전후·결합 설명 |
| 재료·마감 | 물성·공정·세척·접촉·비용과 양립하는가 | 부위별 재료와 마감 |
| 외형 전달 | 선택한 구조·형상이 렌더에도 유지되는가 | 기준 이미지·세부 뷰 |

색·광택에 가려진 비례를 보려면 필요에 따라 회색 모델을 쓴다. 스타일 의뢰에는 원하는 재질·색을 초기에 함께 탐색할 수 있다. 재료를 나중에 입히는 장식층으로만 취급하지 않는다.

**공간 검토:** 치약·물·배터리·기성 부품처럼 넣어야 할 대상이 있으면 외부 윤곽, 실제 내부 공간, 벽·씰·체결·변형·공기 여유를 구분한다. 이미지 속 구멍이나 외부 부피를 사용 용량으로 발표하지 않는다. 부족하면 형상을 수정하거나 기능·용량의 대안을 제시한다.

**기구 검토:** 움직임이나 교체 기능에는 `이동 부품 / 고정 위치 / 이동 경로 / 잠금·복귀 / 조작 접근 / 빠짐·끼임·역류 등 실패 / 확인 방법`을 먼저 적는다. 글이나 이미지로 설명됐다고 작동이 입증된 것은 아니다. 미해결 핵심 기구는 미확인으로 남기고 필요한 정밀도와 시험을 연결한다.

**변경 관리:** 선택한 형태의 비례·분할·재료·부품 위치를 기준으로 저장한다. 다음 수정은 바꿀 부분과 유지할 부분을 나눠 기존 이미지를 입력한다. 회전 뷰·분해도·렌더를 실제 비교하고 생성 이미지의 동일성이나 실측 정확도를 보장하지 않는다.

mm 등 단위를 명시한 하나의 매개변수 표를 기준으로 전체 외형·부품·내부 공간·조립 여유의 관계를 맞춘다. 중요 치수에 값·이유·출처/가정·허용차 확인 상태를 둔다.

사진으로 정확한 크기·재료를 확정하지 않는다. 가려진 내부는 새 설계로 제안한다. 뷰마다 부품 수·곡률·접합 위치가 달라지면 수정한다.

정면·측면·평면·핵심 단면·분해도 중 형상과 조립을 설명하는 뷰를 만든다. 치수선·라벨은 기준 도면 데이터에서 생성한다.

## 공정별 검토

| 공정 | 주요 검토 |
|---|---|
| FDM/SLA/SLS 등 적층 | 장비·소재·방향·후처리·벽·지지·홀·틈·이방성·잔류물 배출 |
| 사출 | 수축·벽 변화·리브/보스·구배·언더컷·파팅·게이트·이젝터·금형 복잡도 |
| CNC | 공구 진입·내부 모서리·깊이/지름·얇은 벽·셋업·표면·측정 접근 |
| 판금 | 두께·재료·금형·굽힘·홀 거리·릴리프·전개·누적 치수·모서리 |
| 목재·가구 | 결 방향·접합·체결·습도 변화·전도·뒤틀림·마감·조립 도구 |
| 봉제·연질 | 원단 방향·시접·재단/봉제 순서·보강·여밈·늘어남·수축 |

이 표는 확인 질문이며 수치 규격이 아니다. 선택 공정의 공식 지침과 업체 조건을 찾아 적용한다. 특정 프린터의 최소 벽이나 공급사의 공차를 다른 공정·재료에 복사하지 않는다. 지침이 다르면 조건 차이를 확인한다.

시제품과 양산 공정을 나눌 수 있다. 3D 프린트 성공이 사출 양산성의 증거는 아니다. 수량 대비 금형비가 크면 표준 부품·판재·가공·적층 등의 대안을 비교한다.

공정 선택이 중요하면 후보의 고정비·개당비·수량·기간을 같은 범위로 비교한다. 근거 있는 견적에서 손익분기 수량은 `(A 고정비−B 고정비) / (B 개당비−A 개당비)`로 계산할 수 있다. 분모 부호·0 여부와 제외 비용을 확인한다. 견적이 없으면 숫자를 채우지 말고 비용 요인과 계산 구조를 제시한다. 재료·형상·금형·일정의 선택 이유도 함께 적는다.

## 부품과 조립

BOM에는 필요에 따라 부품 ID·이름·수량·재료 등급·공정·마감·기성품 규격·출처·확인 상태를 둔다. ID는 도면·모델·조립 순서에서 동일하게 쓴다.

조립 방향·공구 공간·체결 길이·간섭·공차 누적·분해/교체를 검토한다. 스냅핏·힌지·나사·접착의 선택 이유를 설명한다. 전자 제품은 PCB·배터리·커넥터·케이블 굽힘·방열·정비 공간을 실제 부품 치수로 확인한다.

원가 추정은 수량·지역·시점·가정을 붙이고 금형·불량·조립·마감·포장·운송 등 제외 항목을 밝힌다. 실제 견적 없이 확정 원가·납기라고 표시하지 않는다.

## 검증 수준

아래 중 실제 도달 수준을 표시한다. 모든 요청에 마지막 단계까지 강제하지 않는다.

1. 외형 콘셉트: 스타일·기능 방향의 이미지/스케치.
2. 치수·구조 초안: 단위·부품·조립 경로가 연결된 설계.
3. 디지털 검토: 실제 CAD 실행과 가능한 간섭·외형·메시·출력 확인.
4. 시제품 확인: 제작 조건·측정 결과가 기록된 시험.
5. 생산 검토: 제조사 DFM·견적·시험 요구를 반영한 자료.

미실행 CAD 코드, 미수행 강도·방수·안전 시험, 미취득 인증을 완료로 표시하지 않는다. 관련 제품에서만 필요한 안전·규정 조사를 수행하고 중요한 미확인을 구체적 시험 항목으로 남긴다.

제작 요청에는 가능한 편집 원본·치수도·구조·BOM·조립 순서·시제품 계획을 제공한다. 공정 미정이면 대안과 결정에 필요한 정보까지 만든다. 이미지 한 장을 제작 검증된 설계라고 표현하지 않는다.

용량·조립·체결·간섭의 디지털 검토가 필요하면 [cad-handoff.md](cad-handoff.md)를 읽는다. 가장 불확실한 질문부터 작은 모형·결합부 시험 등으로 확인하며 처음부터 완성품 수준의 시제품을 강제하지 않는다.
