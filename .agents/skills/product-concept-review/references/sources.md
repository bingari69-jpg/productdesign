# 보조 평가의 참고 자료
2026-10-31 조사 자료에서 필요한 원리를 새 문장으로 작성했다. 외부 스킬 전문·코드·도구는 설치하거나 복제하지 않았다.

- [Amplitude JTBD SKILL.md](https://github.com/amplitude/builder-skills/blob/main/product-skills/skills/jobs-to-be-done/SKILL.md): 실제 파일 확인. 기능·감정·사회적 욕구와 발언/추론 구분을 참고. 일반적인 감정 가치가 항상 차별성을 만든다는 주장은 채택하지 않음.
- [JTBD Opportunity Discovery README](https://github.com/lishix520/jtbd-skills): README 확인. 구매/교체 동기, 근거·가설·미확인 구분 참고. 계산 스크립트와 시장 성과 주장 검증·설치 없음.
- [IDEO Mash-Ups](https://www.designkit.org/methods/mash-ups.html): 본문 확인. 원하는 경험 특성을 다른 분야와 연결하는 관점. 이 스킬은 발상 강제가 아니라 제안의 사용 장면/차별성 검토에 활용.
- [NN/g 시각 디자인 평가](https://www.nngroup.com/articles/testing-visual-design/): 본문 확인. 첫인상·선호 등 목적에 맞는 방법 구분. 디지털 디자인 중심 자료를 실물 사용성 검증으로 일반화하지 않음.
- [Lyssna 실물 테스트](https://help.lyssna.com/en/articles/4952921-testing-physical-products), [선호 테스트](https://help.lyssna.com/en/articles/4952946-preference-test-sections): 본문 확인. 정지 이미지 비교·질문 구성 참고. 서비스 연결·테스트 배포·유료 패널 실행 없음.
- [AI와 디자인 고착 CHI2024](https://arxiv.org/abs/2403.11164): 초록 확인. N=60 시각 발상 과제에서 초기 예시 고착/다양성 문제 보고. 모든 제품이나 모델의 보편 결과로 취급하지 않음. 평가 과정에서 첫안 정당화를 피하고 개성을 보존할 근거로 활용.

이는 AI 비평 절차의 참고 자료다. 외부 방법을 활용했다고 실제 소비자 조사·독립 평가·매출 예측이 수행된 것은 아니다.
