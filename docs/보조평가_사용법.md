# 제품 콘셉트 보조 평가

기존 product-designer는 창작, 별도 product-concept-review는 구매 이유·소비자 욕구·차별성·매력·구매 장벽 평가를 맡는다. 기존 디자인 스킬 파일은 변경하지 않았다. 보조 평가는 요청 맥락에 맞춰 호출하며 기존 스킬에 강제로 삽입한 자동 후크는 없다.

사용 예:
> $product-concept-review 이 시안을 평가해줘. 대상은 작은 방에서 음악을 듣는 사람이고, 핵심 기능은 휴대와 무드 조명이야. 평가만 해줘.

> $product-concept-review 이 디자인을 평가하고 중요한 지적을 골라 수정 스케치를 만들어줘. 바꾸지 않을 부분은 유지하고 전후를 비교해줘.

결과: 강한 구매 이유·유지할 특징 → 근거가 붙은 우선 지적 → 수용/보류/기각 → 요청한 경우 수정안 → 전후 검토. 기본1회, 필요시2회. 실제 이미지 생성 도구와 파일 확인이 필요하며 스킬 자체는 생성 엔진이 아니다.

같은 대화의 역할 전환과 별도 컨텍스트 AI 평가, 실제 소비자 조사는 서로 다르다. 과거 문맥이 보이는 평가를 블라인드라고 하지 않는다. 독립 에이전트를 자동 생성하지 않는다. 실제 소비자 반응·구매 예측·제조 인증으로 과장하지 않는다.
