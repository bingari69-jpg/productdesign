# 회사 PC에서 제품 디자인 스킬만 받기

저장소: https://github.com/bingari69-jpg/productdesign
브랜치: main
대상은 아래 두 폴더와 그 안의 모든 참고 파일이다.

- `.agents/skills/product-designer/` — 디자인 생성
- `.agents/skills/product-concept-review/` — 소비자 관점 평가·수정 비교

콘팩/영상 스킬·개인 설정·API 키는 필요 없다. 저장소의 designs/ 작업 이미지를 내려받거나 회사 개인 스킬에 복사할 필요도 없다. 이 설치는 별도 웹앱 설치가 아니다. 이미지 생성·검색·도구 연결은 회사의 실행 환경에서 사용 가능한 기능에 따른다.

## 회사 Codex에 그대로 요청

> https://github.com/bingari69-jpg/productdesign 의 main 브랜치에서 .agents/skills/product-designer 와 .agents/skills/product-concept-review 두 스킬만 이 PC의 개인 Codex 스킬 폴더에 설치해줘. 각 폴더의 references와 agents도 포함해줘. 다른 스킬이나 설정은 바꾸지 마. 같은 이름의 기존 스킬이 있으면 개인 수정 여부부터 확인하고 보존해줘. 설치한 파일을 검사하고 적용에 새 대화나 앱 재시작이 필요한지도 알려줘.

스킬 설치 기능이 있는 Codex에서 요청한다. 현재 실행 환경의 skill-installer 지침을 따라 설치할 수 있다. 접근할 수 없는 저장소이면 GitHub 연결/접근 상태부터 확인한다. 비밀키를 채팅에 붙이지 않는다.

## 이미 설치한 회사 PC에서 업데이트

> https://github.com/bingari69-jpg/productdesign 의 main 최신 버전으로 product-designer와 product-concept-review 두 스킬만 업데이트해줘. 로컬 변경이 있으면 덮어쓰지 말고 먼저 비교해줘. 다른 스킬과 환경 설정은 그대로 둬.

이미 열려 있는 대화에는 새 스킬 목록이 즉시 갱신되지 않을 수 있다. 설치 결과 안내에 따라 새 대화를 열거나 Codex를 재시작한 뒤 확인한다. 파일 설치 완료와 현재 대화에서 인식됨은 구분한다.

## 사용

> $product-designer 이 제품을 소비자가 갖고 싶어 할 기능과 디자인으로 개선하고 스케치를 보여줘. 제조 상세보다 구매 이유와 사용 장면을 우선해줘.

> $product-concept-review 방금 시안을 소비자 욕구·차별성·매력·구매 장벽으로 평가하고, 중요한 지적을 반영한 수정안과 전후 비교를 보여줘.

기존 디자이너 스킬과 별도 보조 평가를 함께 사용하는 방식이다. 보조 스킬은 독립 AI 모델이나 실제 소비자가 아니며, 같은 AI의 역할 전환 평가는 실제 시장 반응과 구분한다.

## 동기화 범위

이 저장소는 제품 디자인 전용으로 콘팩 저장소와 분리되어 있다. 회사에는 두 스킬 폴더만 설치한다. 실제 작업 이미지·대화·개별 프로젝트 기록은 스킬 설치로 자동 이전되지 않는다. 필요할 때 해당 작업 자료를 별도로 옮긴다.
